# HostelNexus – Smart Hostel Management System

HostelNexus is a web-based hostel management system developed to simplify and streamline hostel administration. It provides a centralized platform for managing student registrations, room allocations, fee payments, complaints and administrative activities.

## Features

- Student registration and administrator approval
- Student profile management
- Hostel block, room and bed allocation
- Fee management and payment records
- Receipt generation and downloading
- Complaint submission and tracking
- Administrative dashboard
- Rule-based chatbot assistance
- Report generation and export

## Technologies Used

- **Backend:** Python, Flask
- **Database:** MySQL
- **Frontend:** HTML, CSS, JavaScript, Jinja2
- **Libraries:** ReportLab, OpenPyXL

## Project Structure

The project is organized into separate modules for routes, models, services, templates, static resources and database operations.

## Installation and Setup

1. Clone the repository.
2. Create and activate a Python virtual environment.
3. Install the required dependencies using:

   `pip install -r requirements.txt`

4. Configure the MySQL database and connection settings.
5. Start the Flask application using:

   `python app.py`

6. Open the local application URL displayed in the terminal.
